# 新手引导（Guided Tour）

## 背景

Muse 过去只为作者本人设计：入口多（分组、刮削、目录监控、局域网、代理），术语重（番号、刮削、任务看板），
熟悉的人一步到位，第一次打开的人不知道从哪下手。把应用分享给非软件工程背景的朋友时，
「怎么加目录」「刮削是什么」「代理填哪里」是最常卡住的三件事。

这份文档描述第一次打开时自动播放、之后可随时重看的新手引导。

## 目标与非目标

目标：

- 第一次打开时，用十个以内的短步骤讲清**这是什么、入口在哪、下一步该做什么**。
- 重点覆盖新手最容易卡住的三处：添加内容（尤其目录监控）、刮削、代理。
- 只指路，不改变任何业务行为；不收集任何数据。
- 可跳过、可重看；看过一次之后不再自动弹出。

非目标：

- 不做交互式教学（引导期间不替用户点真实按钮、不预置演示数据）。
- 不做功能清单；每一步只讲一个位置。
- 不进入移动端界面（手机端是只读的另一个客户端，流程完全不同）。

## 流程

十个步骤，顺序即新手的使用路径：先理解，再认路，然后加内容、补资料、连着手机看，最后是两处设置。

| # | 步骤 | 指向的界面 | 讲什么 |
|---|------|-----------|--------|
| 1 | 欢迎使用 Muse Video | 居中卡片 | 收藏 ≠ 文件：不复制、不移动、不删除源视频 |
| 2 | 左边是分组 | 左侧边栏 | 全部收藏、分组、演员、刮削任务、查重 |
| 3 | 添加视频 | 头部「+ 添加视频」 | 选文件 / 拖拽；文件多时改用目录监控 |
| 4 | 找到你想看的 | 列表工具条 | 网格 / 列表、卡片大小、排序、硬盘筛选；搜索框在右上角 |
| 5 | 刮削：补齐资料和封面 | 侧栏「刮削任务」 | 单部在详情页重新刮削，批量在设置 → JavBus |
| 6 | 手机也能看 | 头部「局域网访问」 | 手机浏览器打开地址，播放交给 Infuse / VLC；接口无鉴权 |
| 7 | 设置里有什么 | 设置左侧分类 | 服务器 / 目录监控 / 网络代理 / JavBus / FC2CMADB |
| 8 | 添加目录 | 设置 → 目录监控 | 递归收录整个目录，之后新增文件自动进库 |
| 9 | 代理 | 设置 → 网络代理 | 刮削连不上时填 http / https / socks5 代理 |
| 10 | 可以开始了 | 居中卡片 | 收尾与重看入口 |

第 7–9 步在设置页，引导会自己切换页面和左侧分类；其余步骤在影片库。
第 1 步与第 10 步不聚光任何控件，显示为居中卡片。

## 实现

- `frontend/src/utils/tour.ts` —— 步骤数据（`TOUR_STEPS`）、卡片定位与聚光框计算。
- `frontend/src/hooks/useTour.ts` —— 开着/关闭与当前步骤；每次步骤变化通过 `onStep` 告诉外壳切到哪一屏、
  打开哪个设置分类；关闭时 `onSettle` 把用户放回影片库。
- `frontend/src/components/GuidedTour.tsx` —— 遮罩、聚光框、卡片、键盘与焦点管理；只渲染，不写状态。
- `frontend/src/App.tsx` —— 组装三者，启动时用 `getTourSeen()` 读「看过」标记，未看过才自动打开
  （延迟约 0.7s，等首屏数据落地）；任何退出方式都调用 `setTourSeen()`。
- `frontend/src/pages/Settings.tsx` —— `新手引导` 分类：重看按钮 + 常用快捷键。头部 `?` 按钮也指向这里。

### 「看过」标记存在哪里

存在应用数据库的 `settings` 表（键 `tour_seen`，见 `backend/settings`），经 Wails 绑定
`GetTourSeen` / `SetTourSeen` 读写。

早期版本存在 `localStorage["muse.tour.v1"]`，实测不可靠：WebView2 的 LevelDB 日志一旦出现坏记录
（进程被强制结束时可能留下半截写入），之后每次启动都会
`dropping N bytes; Corruption: checksum mismatch`，把坏记录之后的写入全部丢掉——标记每次都写成功，
下次启动却读不到，引导于是每次启动都弹。引导是一次性应用状态，和窗口位置、服务器端口一样归数据库管。
读失败时按「没看过」处理，宁可多放一次，也不要吞掉新用户唯一一次介绍。

### `data-tour` 契约

每个被指向的元素带 `data-tour="<名字>"`，步骤里写同名 `target`。这样文案与界面互不依赖：
改布局只要保留属性，改步骤只要改 `TOUR_STEPS`。

目标在屏幕上找不到时（视图还没渲染、元素被条件隐藏），卡片退化为居中显示——不会出现「卡片指向空白」。
测量带 1.6s 轮询，正好覆盖「切到设置页 → 设置页挂载」这一帧。

### 行为

- 遮罩挡住页面点击；被聚光区域之外的界面不可操作，避免误触刮削或删除。
- 聚光框位于目标外围 6px，卡片优先放在目标上/下方；宽目标（头部、工具条、设置分区）改放侧面，
  窄侧栏条目放右侧，都不遮挡被讲解的控件。
- 键盘：`→` 下一步、`←` 上一步、`Esc` 退出；`Tab` 焦点锁在卡片内；焦点在卡片主按钮上。
- 页面在引导期间 `inert` + `aria-hidden`（WebView 不支持 `inert` 时，遮罩仍会挡住点击）。
- 「看过」标记在**任何**退出方式（走完、跳过、Esc、关闭）下都会写入数据库，重看只用设置里的按钮。
- 引导不改变任何数据：没有预置示例、没有代点按钮、没有网络请求。

## 维护

- 加一步：在 `TOUR_STEPS` 里加一项，给目标加 `data-tour`，并在表中补一行。
- 改文案：只改 `TOUR_STEPS` 的 `title` / `body` / `hint`；文案面向非技术用户，避免「番号解析」「任务队列」这类内部词。
- 改视觉：卡片沿用现有深色 token（`--panel-2`、`--accent`、`--border`），不引入第二套配色；
  `prefers-reduced-motion: reduce` 时关闭卡片入场与光圈呼吸动画。
- 移动端不加载这些文件（`mobile/main.tsx` 自成一套入口）。
