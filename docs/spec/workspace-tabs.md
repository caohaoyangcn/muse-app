# 工作区标签页：演员自动分组与超限关闭

> 桌面端标签条（`WorkspaceTabs`）的行为说明。移动端没有工作区标签，不参与本文的规则。

## 标签种类

| 标签 | 来源 | 能否关闭 | 计入上限 |
| --- | --- | --- | --- |
| 影片库（主页） | 固定标签 | 否 | 否 |
| 影片标签 | 打开一部收藏的详情 | 是 | 是 |
| 演员作品标签 | 从演员索引 / 影片详情打开某演员的作品列表 | 是 | 是 |

## 演员自动分组

- 依据是共享读模型 `Video.actors`：来自 `video_jav.actors_json`，由 `api.Library` 的读模型填充。**不是** `videos` 表字段，没有数据库迁移。
- 演员名使用**演员合并后的规范名**（`jav.ActorsByVideo`），所以标签组和演员索引、演员作品页指向同一个人。同一影片的演员名会去重、排序。
- 只有**至少 2 个同时打开的影片标签**共享同一演员时才成组。未刮削、没有演员的影片不参与分组。
- 一部影片只归入一个组。若它同时匹配多个达到条件的演员，归入“当前未分组标签中影片数最多”的演员；数量相同则取最早出现的演员，再相同则按名称排序。这样可以避免同一标签在标签条里出现两次。
- 分组算法是贪心的：每轮选出当前最大的演员簇，把这些标签移出待分组集合，再继续。组按最早成员在标签条中的位置排列，组内保持标签原有顺序。
- 组内标签减少到 1 个时组自动解散，剩余标签回到未分组区。

## 折叠与展开

- 组头是 Chrome 风格的彩色演员组：实心演员色药丸（名称 + 成员数 + 折叠箭头），下面垫一层同色淡底，外框与成员标签的下划线使用同一种颜色。
- 颜色由演员名稳定哈希到 Chrome 的九色调色板（蓝 / 红 / 黄 / 绿 / 粉 / 紫 / 青 / 橙 / 灰）；同一个演员始终同色，新增其他组不会让已有组换色。
- 组头显示演员名、成员数、折叠箭头；点击组头切换折叠。
- 折叠时只显示实心药丸，不再显示组底色和外框。组内有当前激活标签时药丸与组边框保持高亮，内容区仍显示该标签。
- 手动折叠当前组不会立即被弹开。通过后退/前进、`Ctrl+Tab`、`Ctrl+PageUp/Down` 或刮削后新入组，当前标签进入一个折叠组时，该组自动展开。
- 折叠状态是会话状态，不写数据库也不写 `localStorage`；标签本身也不跨重启恢复。

## 超限自动关闭

- 上限：**12 个非主页标签**，影片标签与演员作品标签共用。
- 判定依据是**最近一次激活时间（LRU）**，由 `activateTab` 打点；不是打开顺序，也不是 `lastOpenedAt`（播放时间）。
- 超过上限时，从所有非当前标签中按 LRU 关闭最旧的若干个。**当前激活标签永不自动关闭**。
- 一次批量关闭，不逐个切换；同时清理滚动位置、标签历史栈和 LRU 记录。
- 关闭后用现有 toast 提示关闭数量与被关闭标签名。
- 自动关闭包含演员作品标签；演员索引本身不受影响，需要时可以重新打开。

## 实现位置

- `frontend/src/utils/tabGroups.ts`：纯函数分组建模。
- `frontend/src/components/WorkspaceTabs.tsx`：分组标签条、组头折叠与高亮。
- `frontend/src/pages/Library.tsx`：折叠状态、视觉顺序、LRU 打点与超限 effect。
- `backend/jav/service.go`：`ActorsByVideo` 规范演员投影。
- `backend/api/library.go`：把演员并入共享 `Video` 读模型。
- `backend/video/model.go`：`Video.Actors` 字段。

## 非目标

- 不提供手动创建、重命名、删除标签组。
- 不支持把标签拖入/拖出组。
- 不持久化标签页、组或折叠状态。
- 不改变移动端底部标签栏。
