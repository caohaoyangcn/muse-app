# Muse 收藏助手 for JavDB

在 JavDB 的影片卡片上，一眼看出这个番号是否已经收藏到本机 Muse。

## 它做什么

JavDB 的每张影片卡片右上角会出现一个角标。把鼠标移上去，扩展就会向本机 Muse
查询该卡片上的番号：

| 角标 | 含义 |
|---|---|
| `✓` / `✓2` | 已收藏（2 表示库里有多个版本） |
| `✗` | 没有收藏 |
| `🗑` | 只在 Muse 回收站里 |
| `⚠` | Muse 未连接（应用没开，或改过端口） |
| `?` | 这张卡片没有番号字段，不查询 |

点击角标会展开命中的收藏（封面、文件名、分辨率、大小、演员，以及「回收站」「网盘」
「磁盘未接入」标记），点其中一条即可在 Muse 中打开该收藏。

## 番号从哪里来

**直接读 JavDB 页面上已经渲染出来的片号**（卡片标题里的 `<strong>` 元素），
只做去空白、转大写的字面整理。扩展**不做**任何"从标题里猜番号"的解析——猜错会把
一张卡片标成另一部作品，而页面本身已经告诉我们它是哪一部。

番号在 Muse 里如何匹配（已刮削的番号优先，未刮削的看文件名；上下集分开）由
Muse 后端统一回答，细节见 `docs/spec/javdb-browser-extension.md`。

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启右上角「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本目录。
3. 启动 Muse。局域网服务随应用自动开启，默认端口 **8899**。
4. 打开 JavDB 任意列表页（搜索结果、演员页、排行榜）。

## 权限与隐私

| 权限 | 为什么需要 |
|---|---|
| `host_permissions: 127.0.0.1:8899` | 向本机 Muse 发查询。端口固定，所以权限写成具体的端口 |
| `storage` | 记住 Muse 地址 |
| 内容脚本（JavDB 域名） | 在卡片上显示角标 |

- 只读：扩展没有任何修改收藏库的动作。
- 只有番号会离开浏览器，而且只发给本机 `127.0.0.1`；不发送页面地址、Cookie 或浏览记录。
- Muse 端只为这一个端点开启了 CORS，并限定 JavDB 的域名；其他 `/api` 路径仍然只允许同源。

## 修改端口

扩展的站点权限写死为 8899。若你修改了 Muse 的端口，需要在 `manifest.json` 的
`host_permissions` 里加上新端口，并在 `chrome://extensions` 中点「重新加载」。

## 已知限制

- 只支持桌面 Chrome / Edge（Manifest V3）；手机浏览器不能安装扩展。
- 只注入 `javdb.com` / `www.javdb.com` / `jav.app` 及其子域。JavDB 的编号镜像
  （如 `javdb581.com`）无法写成合法的 match pattern（host 通配符只能是整个最左标签），
  需要使用时把该域名加进 `manifest.json` 的 `matches`；Muse 端已允许这些镜像来源。
- JavDB 改版导致卡片结构变化时，角标可能不出现：`content.js` 顶部的
  `CARD_SELECTOR` / `CODE_SELECTOR` 两行是唯一需要改的地方。
