Muse 是一个本地优先的视频收藏管理器。你不需要先把文件搬进某个“库目录”：把视频拖进来，Muse 记住它在哪里、叫什么、多大、多长，然后给你缩略图、搜索、分组、刮削和手机访问。

它只做一件事：**让你更快找到并播放自己的本地影片，同时保证不碰你的文件。**

> **收藏 ≠ 文件。** 数据库只保存路径和元数据；移除一条收藏只会把它移入回收站（可恢复），彻底清理时也只删除记录和生成过的缩略图/封面，原视频一个字节都不会少。

## 为什么是 Muse

大多数媒体库是“导入式”的：先复制或移动文件，再由它接管。Muse 反过来——**文件留在原地，索引归你所有**。

- **不整理你的硬盘。** 你继续用自己的方式命名文件夹、划分磁盘。Muse 只旁路记录，不复制、不移动、不重命名、不删除。
- **文件搬家，记录跟着走。** 用文件大小加首尾内容算出的指纹，Muse 能在文件被挪到另一块盘、另一个目录后把它认回原记录。分组、点赞、封面和刮削资料都不会丢。
- **库不会假装一切正常。** 文件缺失标 ⚠，同番号多版本和内容重复分别列清单，没刮削的片子也保持可见。你可以相信列表里看到的东西。
- **手机是第二块屏。** 同一个收藏库，同一套业务规则；手机浏览器打开就能浏览和播放，不需要把片子传到云端。

## 功能一览

| 你会做的事         | Muse 怎么做                                                                                                                                                                                   |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **把片子收进来**   | 拖拽到窗口任意位置，或点「+ 添加视频」批量选择；也可以让「目录监控」递归收进整个文件夹。支持 `.mp4` `.mkv` `.webm` `.mov` `.avi` `.m4v`；后台自动读取时长、分辨率与编码，并抽取画面做缩略图。 |
| **网盘也能收**     | 可选接入标准 WebDAV（比特球经 OpenList 桥接）：只读浏览、多选加入收藏、生成封面；播放直接交回 OpenList。不用网盘的用户不需要安装 OpenList，详见[云盘设置](docs/cloud-drive-setup.md)。 |
| **把库整理清楚**   | 多级分组（可拖拽排序）、点赞、标题与备注、自定义封面时间点、网格/列表切换。整理的是收藏，不是磁盘上的目录。                                                                                   |
| **几秒内找到**     | 按文件名或完整路径模糊搜索；按硬盘/卷多选筛选；`Ctrl + F`（macOS 为 `⌘ F`）随时回到搜索框。                                                                                                   |
| **资料一次补齐**   | 按番号查询 JavBus / Avmoo / FC2CMADB，回填标题、演员、标签、发行日期与封面；支持批量刮削、失败重试、自定义代理与 Cookie。演员索引会聚合头像、生日、身高与三围。                               |
| **清掉重复收藏**   | 「查重」提供两份清单：**同番号多版本**（不同清晰度或压制组）与**内容重复**（同一份文件被收了两次，哪怕改过名、换过盘）。可以保留一个，也可以全部保留。                                        |
| **文件挪了能接回** | 启动时和播放前检查文件，丢失的标 ⚠。被移动的文件再次入库时，Muse 按内容指纹自动接回原记录，资料原样保留。                                                                                     |
| **删错了能找回**   | 移除收藏、以及文件缺失的自动清理，都会先进入**回收站**并保留分组、点赞与刮削资料；默认保留 14 天（可调），期间随时恢复，超期自动清理。回收站不复制、不删除源视频。 |
| **躺到床上看**     | 应用启动即开启局域网页面，手机浏览器打开顶部地址即可浏览、搜索、看详情。iPhone/iPad 可把播放交给 Infuse 或 VLC，直接串流原始文件，不在电脑上转码。                                            |

## 快速开始

### Windows 10/11（x64）

1. 打开 [Releases](https://github.com/caohaoyangcn/muse-app/releases/latest)，下载最新的 `Muse-<版本>-win64.zip`。
2. 把**整个文件夹**解压到一个固定位置，例如 `D:\Apps\Muse`。不要只把 `Muse.exe` 单独拖出来——同目录的 `ffmpeg.exe` / `ffprobe.exe` 负责缩略图和视频信息。
3. 双击 `Muse.exe`。首次运行 Windows 可能弹出「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可；这是未签名程序的常规提示。
4. 把视频拖进窗口，或点左上角「+ 添加视频」。第一次打开会自动播放一段十步的新手引导，按 `Esc` 可随时退出。

无需安装、无需管理员权限。数据默认保存在 `%LOCALAPPDATA%\Muse\`，和程序文件夹分开，覆盖升级不会丢收藏。

> **第一次用？** 先拖一部片子进来，等缩略图出现；右键卡片可以打开视频、定位文件或复制路径。想收整个目录，去「设置 → 目录监控」。

### macOS 13+（Apple Silicon）

目前 Release 只提供 Windows 包，macOS 需要从源码构建：

```bash
xcode-select --install
brew install go node ffmpeg
go install github.com/wailsapp/wails/v2/cmd/wails@v2.15.0

git clone https://github.com/caohaoyangcn/muse-app.git
cd muse-app
wails build --clean --platform darwin/arm64
open build/bin/Muse.app
```

请确保 `$(go env GOPATH)/bin` 在 `PATH` 中，否则会找不到 `wails`。构建后可以把 `Muse.app` 复制到 `/Applications`。目前只在 Apple Silicon + macOS 13+ 上验证过，Intel Mac 与 Linux 暂未提供构建。

## 在手机上使用

Muse 启动时会自动开启局域网服务，界面顶部会显示形如 `http://192.168.0.100:8899` 的地址。默认端口是 `8899`，可在「设置 → 服务器」中修改。

1. 确认手机和电脑连在同一个 Wi-Fi（不要开访客网络/AP 隔离）。
2. 在手机浏览器打开界面顶部显示的地址。
3. iPhone/iPad 播放时会让你选择 Infuse 或 VLC，之后会记住选择；其他设备可以复制播放地址，粘到已安装的播放器里打开。

Windows 第一次启用局域网访问时，建议右键 `Muse.exe` →「以管理员身份运行」一次，让应用自动添加防火墙放行规则；也可以在 Windows 安全中心手动允许 Muse。macOS 若弹出传入连接提示，请选择允许。

**手机上可以：** 浏览、搜索、按分组/演员筛选、排序、看详情、查重、编辑标题与备注、点赞、移入回收站、从回收站恢复或彻底删除。

**手机上不可以：** 添加视频、发起刮削、管理分组、配置目录监控与设置。这些依赖原生文件对话框、FFmpeg 或服务器文件系统，保留在桌面端。

> ⚠️ **安全提示：** 局域网服务**没有密码**，并且随应用自动开启。同一网段内的任何设备都能访问，包括调用写操作（例如移除收藏）。请只在可信网络中使用；不需要时点界面顶部的「停止」关闭，下次启动仍会自动开启。

打不开时依次检查：手机与电脑是否在同一局域网 → Windows 防火墙是否放行 → 手机是否开了 VPN / 私有 DNS / 代理 → 地址是否为界面显示的私网 IP（`192.168.*`、`10.*`、`172.16~31.*`）。`169.254.*` 这类链路本地地址手机无法访问。

## 数据与隐私

所有数据都在你自己的电脑上：

```text
Windows: %LOCALAPPDATA%\Muse\
macOS:   ~/Library/Application Support/Muse/

├── app.db          # SQLite 收藏库（路径、元数据、分组、刮削资料）
├── thumbnails\     # 自动生成的缩略图
├── covers\jav\     # 刮削封面
├── avatars\        # 演员头像
└── logs\app.log    # 运行日志（超过 10 MB 时启动会清空）
```

- **无账号、无云端、无遥测。** 除了刮削、局域网访问和用户主动配置的 WebDAV 网盘，断网也能正常使用。
- **备份就是复制文件夹。** 换电脑或重装系统时，把整个 `Muse` 数据目录带走即可；换新版本只覆盖程序文件夹，不用碰数据目录。
- **Muse 不保存视频内容。** 网盘播放由 OpenList 负责；Muse 只保存记录、封面与元数据。刮削和网盘连接是仅有的出站请求。 番号、文件名和封面地址会发送给 JavBus / Avmoo / FC2CMADB；只读 WebDAV 请求只会发往你自己配置的地址。网络不通时刮削/网盘失败是预期行为，可以配置代理或稍后重试。
- **删除收藏不会删文件。** 移除只会把记录移入回收站；彻底删除、清空回收站或超期清理也只删除数据库记录与它生成的图片。想删原片，请自己在文件管理器中操作。

## 常见问题

### 会动我的视频吗？

不会。Muse 不复制、不移动、不重命名、不删除源视频。移除收藏、清空分组、查重时“保留一个”，操作对象都只是数据库记录和生成的图片；移除还会先进入可恢复的回收站。

### 缩略图一直是灰的，或者双击没反应？

缩略图灰色，通常是 `ffmpeg.exe` / `ffprobe.exe` 没和 `Muse.exe` 放在一起；Windows 包默认已经带上，手动移动过 exe 的话把它们放回去。双击完全没窗口，先确认系统有 WebView2 运行时（Win11 和较新的 Win10 自带，缺失时 Wails 会弹窗引导安装），再看 `%LOCALAPPDATA%\Muse\logs\app.log`。

### Windows 提示“Windows 已保护你的电脑”？

程序没有购买代码签名证书，SmartScreen 会对所有这类 exe 弹出提示。点「更多信息 → 仍要运行」。杀毒软件的启发式误报也可以把整个文件夹加入信任。

### 手机打不开页面？

优先检查三点：手机和电脑是否在同一个 Wi-Fi、Windows 防火墙是否放行、路由器是否开启了访客网络或 AP 隔离。详细步骤见上面的[手机使用](#在手机上使用)。

### 刮削一直失败？

先用浏览器确认能打开对应站点；网络不稳定时在「设置 → 网络代理」配置 http / https / socks5 代理。站点结构变化、限流或需要 Cookie 时，也可以在设置里补充 JavBus Cookie。失败任务会留在「刮削任务」里，可以重试。

### 换电脑或重装系统后收藏还在吗？

在，只要你保留了 `%LOCALAPPDATA%\Muse\`（macOS 为 `~/Library/Application Support/Muse/`）。把数据目录复制到新机器，再确认视频文件路径可访问即可。如果盘符或目录变了，重新添加文件时 Muse 会尝试按内容指纹接回原记录。

### 支持哪些格式？能播 HEVC 吗？

收藏支持 `.mp4` `.mkv` `.webm` `.mov` `.avi` `.m4v`。桌面端调用系统默认播放器，能不能解码取决于你安装的播放器；手机端由 Infuse / VLC 直接解码原始文件，支持范围也取决于客户端。Muse 本身不做转码。

### 有 Intel Mac 或 Linux 版吗？

目前只在 Windows 10/11 x64 和 Apple Silicon macOS 13+ 上验证。Intel Mac 与 Linux 没有官方构建，也没有测试覆盖。

## Muse 不做什么

Muse 刻意保持小而专注：

- 不是云媒体服务器：不做服务端转码、多用户、账号体系或公网访问。
- 不是下载器：不提供、不托管、不分发任何视频内容。
- 不是文件整理器：不会替你重命名、移动或清理磁盘。
- 手机端不是桌面端的完整替代：添加、刮削、封面选帧、演员合并、分组管理和设置留在桌面。

如果你需要的是“在任何地方用任何设备访问一个由服务器转码的媒体库”，Muse 不是那个工具。如果你想要的只是**在自己的电脑上，把本地片子管得清楚、找得很快、看得舒服**，它就是了。
