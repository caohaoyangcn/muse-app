Muse — 本地视频收藏管理器（Windows 64 位）
==================================================

一、怎么启动
--------------------------------------------------
1. 先把整个文件夹解压到硬盘上的一个固定位置（例如 D:\Apps\Muse），
   不要直接在压缩包里双击，也不要只把 Muse.exe 单独拖出来。
   同目录的 ffmpeg.exe / ffprobe.exe 用来读取视频信息和生成缩略图，
   少一个就会出现「缩略图一直是灰的」。
2. 双击 Muse.exe 即可，无需安装、无需管理员权限。
3. 第一次打开会自动播放一段「新手引导」：用聚光依次指出分组、添加视频、
   刮削、手机访问，以及设置里的目录监控和网络代理。随时可以按 Esc 退出，
   之后点界面右上角的 ? 或「设置 → 新手引导」就能重看。
4. 添加视频：把视频文件拖进窗口，或点界面左上角的「+ 添加视频」。
   文件很多时更推荐「设置 → 目录监控 → 添加目录」，整个文件夹一次收进来。
   Muse 只记录文件路径，不会复制、移动或删除你的视频。

二、第一次运行可能遇到的提示
--------------------------------------------------
1. 「Windows 已保护你的电脑」（SmartScreen 蓝色窗口）
   这是所有没有购买代码签名证书的程序都会遇到的提示，不是病毒。
   点「更多信息」→「仍要运行」。

2. 杀毒软件提示未知程序 / 风险
   Muse.exe 是开源程序编译出的未签名可执行文件，容易被启发式规则误报。
   可以把它加入杀毒软件的信任列表。

3. 启动时提示缺少 WebView2
   Windows 11 和较新的 Windows 10 自带 WebView2 运行时；
   如果提示缺失，按弹窗里的链接安装一次即可：
   https://go.microsoft.com/fwlink/p/?LinkId=2124703

三、手机 / 平板通过局域网访问（可选）
--------------------------------------------------
应用启动后会在界面顶部显示形如 http://192.168.x.x:端口 的地址，
同一 Wi-Fi 下的手机浏览器打开即可浏览收藏。

打不开时依次检查：
1. 电脑上的 Windows 防火墙是否放行：右键 Muse.exe →「以管理员身份运行」一次，
   应用会自动添加放行规则；也可以在「Windows 安全中心 → 防火墙和网络保护
   → 允许应用通过防火墙」里手动允许 Muse。
2. 手机与电脑在同一 Wi-Fi，且路由器没有开「访客网络 / AP 隔离」。
3. 关掉手机上的 VPN、私有 DNS 和代理。
4. 端口每次启动可能不同，请以界面顶部显示的地址为准。

注意：局域网服务没有密码，同一网络下的其他设备也能修改收藏。
在咖啡厅、宿舍等公共网络里请点界面上的「停止」关掉它。

四、JavDB 浏览器扩展（可选）
--------------------------------------------------
browser-extension 文件夹里是一个 Chrome / Edge 扩展：在 JavDB 的影片卡片
右上角显示角标，告诉你这个番号是否已经收藏在 Muse 里。

安装（只需一次）：
1. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
2. 打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本文件夹下的 browser-extension。
4. 保持 Muse 运行，打开 JavDB 任意列表页，鼠标移到卡片右上角的角标上。

角标含义：✓ 已收藏（数字是多版本数量）· ✗ 未收藏 · 🗑 仅在回收站 ·
⚠ Muse 未连接 · ? 卡片上没有番号。

说明：
- 扩展是只读的，不会修改你的收藏，只把番号发到本机 127.0.0.1。
- 扩展固定连接默认端口 8899。如果你在「设置 → 服务器」里改过端口，
  角标会显示未连接：改回默认端口，或按 browser-extension\README.md 调整。
- JavDB 更换域名（javdb581.com 之类）后，需要更新扩展的权限与 Muse 的
  允许来源；见 browser-extension\README.md。

五、数据存在哪里
--------------------------------------------------
%LOCALAPPDATA%\Muse\
  app.db            收藏库（SQLite，只存路径和元数据）
  thumbnails\       缩略图
  covers\           刮削封面
  avatars\          演员头像
  logs\app.log      运行日志（超过 10MB 时启动会清空重来）

删除收藏只删数据库记录和缩略图，不会动你的视频文件。
换新版本、甚至删掉程序文件夹，只要这个目录还在，收藏就还在。

六、升级
--------------------------------------------------
用新版本文件夹里的全部文件覆盖旧文件夹即可（保留 %LOCALAPPDATA%\Muse\ 不动），
数据库结构会在启动时自动迁移。
